# Gitstar 实现记录

## 工程

- `windows/Gitstar.Core`：平台无关模型、版本/通道/架构/路径规则。
- `windows/Gitstar.Desktop`：WPF 主界面、浏览器设备授权、GitHub REST/GraphQL、SQLite、DPAPI、注册表检测、下载、ZIP、Git、Release、托盘与自启动。
- `windows/Gitstar.Checks`：不依赖 NuGet 测试框架的行为和基础设施检查；使用固定测试凭据与临时文件。
- `windows/installer`：Inno Setup 的当前用户安装器，校验 x64 Desktop Runtime 10.x。
- `windows/build.ps1`：从 `D:\Agant\toolchain\dotnet` 构建 framework-dependent x64 ZIP 与安装版。

Komi Store 保留在 `upstream-komi` 作为 Release/安装行为参考。本版 C# 独立实现，没有复制 GPL 的 Obtainium 源码。现阶段窗口协调和服务实现尚未完全拆为独立 Application/Infrastructure 程序集。

## 复现

```powershell
& D:\Agant\toolchain\dotnet\dotnet.exe run --project windows\Gitstar.Checks\Gitstar.Checks.csproj -c Release
& D:\Agant\toolchain\dotnet\dotnet.exe run --project windows\Gitstar.Checks\Gitstar.Checks.csproj -c Release -- --live-public
& .\windows\build.ps1
& D:\Agant\toolchain\dotnet\dotnet.exe .\artifacts\Gitstar-win-x64\Gitstar.dll --render-smoke D:\Agant\github-update\artifacts\Gitstar-preview.png
```

DPAPI 必须在有登录凭据的真实 Windows 用户上下文运行。受限沙箱报凭据不可用时，不采用明文回退；正常用户上下文已通过往返验证。Inno 编译器 7.1.0 下载自官方 GitHub Release，安装前已核验 Authenticode 有效、签名方 Pyrsys B.V.，工具位于本项目 `build-tools`。

### 已关注但未加入 GitHub 分组
只读查询本地任务确认三次添加操作均在分组阶段未确认；旧授权请求 repo read:user workflow 缺少 user。修正为 repo user workflow，写入前读取 OAuth scope 并提示旧令牌重新授权，设置提供保留原账号偏好的重新授权入口。GitHub 不提供 OAuth scope 头时仍由服务端判断权限，不误拒绝其他令牌类型。分组返回成员必须与提交一致；失败保留具体 API 原因，不再被笼统的待核实提示覆盖。

### 授权持久化和自动续期
旧实现 Device Flow 只取 access_token，丢弃 refresh_token、expires_in、refresh_token_expires_in；OAuth App 开启令牌到期时无法续期。新授权记录整体 DPAPI 加密，含访问/续期令牌、期限、scope、Client ID，优先加载新记录并兼容旧 token。续期用设备授权获得的 refresh token，不要求内置 Client Secret；单个 semaphore 合并 8 个并行请求的续期操作，返回的新令牌对及时持久化。保存设置重建 API 时保留完整授权；重新授权失败保留原登录，注销清除两种格式。
新增七项检查覆盖旧令牌兼容、凭据无明文持久化、数据库重开字段保留、并行续期仅一次、重载后无需浏览器/续期、网络失败保留凭据、注销清除；共 94 项离线/模拟检查。真实账号的到期续期尚需在线验收，旧版丢弃的 refresh token 无法恢复，需要一次重新授权。
用户要求将仓库读取并发上限增加到 24。对应模拟批次使用 60 个仓库，检查 24 并行上限、全量恰好一次、取消和限流停止派发；授权续期合并检查也扩大到 24 个并行请求。
内存优化：历史版本对象不再全量常驻，按仓库正式/测试通道和已绑定 TagPrefix 保留候选；旧缓存载入时压缩，下一次保存写入精简缓存。Release 每页 30 条，HTTP 响应流解析并就地消费，省去大 UTF16 字符串及 JsonElement 克隆；SQLite JSON 直接读写 UTF8 字节。只为可见筛选结果创建持久按钮状态；头像内存缓存最多约 128 个已完成条目，活动请求不驱逐。24 路并行不变。新增 5 项规则/模拟分页测试：10000 历史记录压缩至不超过 4 条，同时保留两个通道、较旧绑定版本线及完整日志。真实 890MB 进程未做堆转储，实际账号运行峰值仍需复查，不能把测试记录减少比例当作进程内存降低比例。
